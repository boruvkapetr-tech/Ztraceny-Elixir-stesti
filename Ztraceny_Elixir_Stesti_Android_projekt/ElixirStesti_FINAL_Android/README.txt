ZTRACENÝ ELIXÍR ŠTĚSTÍ HRADNÍHO PÁNA — ANDROID PROJEKT

Obsahuje nativní Android aplikaci (Java), český příběh, obrázky dodané uživatelem,
kontrolu pěti řešení a uložení postupu offline.

Jak sestavit APK:
1. Nainstalujte Android Studio a otevřete tuto složku jako projekt.
2. Nechte Android Studio stáhnout potřebné Android SDK/Gradle komponenty.
3. Zvolte Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Výstup obvykle najdete v app/build/outputs/apk/debug/app-debug.apk.
5. Přeneste APK do Android telefonu a povolte instalaci z daného zdroje.

UPOZORNĚNÍ: Projekt nebyl v tomto prostředí zkompilován ani otestován na telefonu.
V této dodávce není hotové APK. Potřebuje Android Studio a síť pro závislosti.

Průběh: start na Křivoklátě -> zadání názvu -> odhalení další lokace ->
ruční potvrzení příjezdu -> další kapitola -> finální kód 3543.
Zadání šifer jsou na papíře. Aplikace nesleduje polohu ani nepotřebuje internet.
